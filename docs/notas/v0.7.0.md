Checklist por conquista.

- **Cada conquista tem o seu checklist**: selecione a conquista no planejador e adicione os passos dela. Eles só
  aparecem com essa conquista aberta, e a linha dela no plano mostra quantos já foram feitos (ex.: "Checklist 1/3").
- O **checklist do jogo** continua para o que vale para o jogo todo. As tarefas que você já tinha ficam nele, porque
  o app não tem como saber de qual conquista eram: com uma conquista selecionada, use o botão ao lado da tarefa para
  passá-la para ela (e de volta, se errar).
- Subir e descer uma tarefa agora mexe só dentro da lista dela.
